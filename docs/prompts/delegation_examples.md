# 위임 프롬프트와 검증 루프 기록 — 목차

에이전트(Claude Code)에 맡긴 작업마다 **위임 프롬프트 → 에이전트가 한 일 → 사람의 확인(결함·오답 주입)**을 한 파일에 남긴다.
판정 기준(골든 케이스의 기대값, evals 데이터셋·합격선·judge 지시)은 위임 범위에서 빼고, 그 기준을 실행하는 장치(하니스·러너)만 맡긴다.

| 기능 | 기록 | 결함·오답 주입 결과 |
|---|---|---|
| 골든 테스트 하니스(결정 층) | [delegation_golden.md](delegation_golden.md) | 결함 9건 모두 잡음(구현 8건 + 케이스 파일 기대값 1건) |
| evals 러너(통계 층) | [delegation_evals.md](delegation_evals.md) | 오답 9건 모두 잡음 |

공통 규칙(AGENTS.md 4장): 테스트·골든 케이스는 사람이 승인해 바꾸고, skip·xfail·케이스 삭제로 통과시키지 않으며, 통과했다면 케이스마다 왜 통과하는지 근거를 남긴다.
